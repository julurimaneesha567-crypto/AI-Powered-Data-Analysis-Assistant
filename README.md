# 📊 AI-Powered Data Analysis Assistant

🚀 **Live Application Link**:(https://ais-pre-pwulivsx2c4lk3p6hjvqck-218526102965.asia-southeast1.run.app)

An end-to-end interactive data analytics platform featuring:
- **CSV Data Ingestion**: Drag-and-drop CSV upload or pre-configured datasets.
- **Data Quality & Auto-Cleaning**: 1-click deduplication & Mean/Mode null imputation.
- **Dynamic Analytics Dashboard**: Interactive charts (Bar, Line, Area, Pie) powered by Recharts.
- **AI Deep Insights & Narrative**: Executive summaries, risk analysis, and driver breakdown via Gemini 3.8.
- **Ask AI Data Chat**: Conversational dataset Q&A synchronized to your active records.
- **Executive Reports**: Board presentation summary ready for print and PDF export.
